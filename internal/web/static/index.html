          Tools that go with these

          isoshelf keeps the images current. Writing one to a drive is somebody else's job, and these are the ones worth having. Independent projects, none affiliated with isoshelf.

          • Ventoy Turns one USB stick into a boot menu of every image you drop on it, so adding an image is a file copy rather than a rewrite. The reason a folder of ISOs is worth keeping current in the first place.
          • Rufus Writes one image to a USB stick on Windows, and is the usual answer when a stick has to boot something awkward.
          • balenaEtcher Writes one image to a USB stick or SD card, on Windows, macOS and Linux, and checks what it wrote afterwards.
          • Raspberry Pi Imager Writes card images for a Pi and the other small boards, and sets up the first boot before it does.

            What is this file?

            isoshelf reads what the disc says about itself and compares it with the catalog. Nothing is renamed or moved: your answer is only remembered, so the file can be checked for updates like the rest.

            Choose it from the catalog
              Name it myself

              For images no list will ever know: one you built, one you customized, or a distribution isoshelf hasn't been told about. It is saved to your own catalog file, and isoshelf will recognize this filename from now on. It can't be checked for updates: that needs an official place to read checksums from.

              Choose a folder

              A Ventoy drive, any folder of images (a NAS share, your downloads, card images waiting to be written), or Proxmox ISO storage. Just plugged a drive in? Press Refresh.
